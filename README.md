# SmartKos – Sistem Pengelolaan Cashflow Anak Kos

**SmartKos (Smart Economy)** merupakan aplikasi berbasis Java yang dirancang untuk membantu anak kos dalam mengelola keuangan sehari-hari. Aplikasi ini membantu pengguna mencatat pemasukan, pengeluaran, melihat riwayat transaksi, dan memantau saldo secara lebih teratur.

## Tujuan Aplikasi
- Membantu anak kos mengelola keuangan.
- Memudahkan pencatatan pemasukan dan pengeluaran.
- Mengetahui kondisi saldo keuangan.
- Membantu pengguna memantau riwayat transaksi.

## Fitur Aplikasi
1. **Tambah Pemasukan** – Mencatat uang yang diterima.
2. **Tambah Pengeluaran** – Mencatat uang yang digunakan.
3. **Riwayat Transaksi** – Melihat daftar transaksi.
4. **Lihat Saldo** – Menampilkan total pemasukan, pengeluaran, dan saldo akhir.
5. **Simpan Data** – Menyimpan data transaksi.
6. **Keluar** – Mengakhiri penggunaan aplikasi.

## Teknologi yang Digunakan
- Bahasa Pemrograman: Java
- IDE: Apache NetBeans IDE 31
- Konsep Pemrograman: Object-Oriented Programming (OOP)
- Penyimpanan Data: File Serialization

## Struktur Project
- `src/` – Berisi source code aplikasi.
- `nbproject/` – Konfigurasi project NetBeans.
- `build.xml` – Konfigurasi proses build.
- `manifest.mf` – Informasi manifest aplikasi.

## Cara Menjalankan Aplikasi
1. Download atau clone repository SmartKos.
2. Buka Apache NetBeans IDE.
3. Pilih **File → Open Project**.
4. Pilih folder SmartKos.
5. Jalankan project menggunakan tombol Run.
